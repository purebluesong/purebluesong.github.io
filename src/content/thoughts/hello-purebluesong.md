欢迎来到 **purebluesong**。

这是瑞鹏的个人站点。之后会在「个人思考」写下技术笔记、项目复盘，以及一些值得留下来的日常；「信息整合」收拢静态条目；「作品」放站点与小游戏；「关于」只展示 GitHub 上公开可见的信息。

站点用 [Astro](https://astro.build/) 构建，托管在 GitHub Pages。要新增思考，只需在 `src/content/thoughts/` 下添加 Markdown（或 MDX）文件。
